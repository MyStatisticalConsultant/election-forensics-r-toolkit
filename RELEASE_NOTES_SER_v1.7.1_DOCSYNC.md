# v1.7.1-docsync (usklađivanje dokumentacije; razvojna verzija)

Ovo izdanje donosi **samo izmene dokumentacije** u razvojnom repozitorijumu v1.7. Postojeći `.R` skriptovi, testovi i statističke formule nisu menjani. Novi modul `klimek` v0.1.0-dev i dalje zahteva izvršavanje RStudio testova i vizuelni pregled grafikona pre nego što se može označiti kao validiran.

Ažurirani su korenski README dokumenti, GitHub uputstva i kontrolne liste na oba jezika; dodati su dvojezični registar modula i tok rada; usaglašeni su EN/SR arhitektura i README pripremnog modula, kao i korisnička uputstva za Klimek. Istorijske beleške ostaju neizmenjene. Manifest SHA-256 je ponovno izračunat.

**Praktično pravilo:** nov modul se dodaje kao zaseban folder, uz usklađivanje pogođene dokumentacije. Nije nužno ponovo instalirati ili izvršavati sve prethodne module. Već pripremljene RZS baze mogu se koristiti ako su izvor i šema nepromenjeni. Lokalne baze i izlaze treba sačuvati.
