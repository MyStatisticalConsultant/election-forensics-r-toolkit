# Klimek-style cumulative election curves — R module v0.1.4

**Election Forensics R Toolkit** · [Srpski (latinica)](README_SER.md) · [Detailed user guide](USER_GUIDE.md)

A locally executed, **single-file R analysis** that creates cumulative vote-versus-turnout curves, comparison graphics and reproducible numerical summaries from the `Main`, `Master` and `Options` worksheets generated by `RZS_data_preparation.R`. It works with the already validated 2017 presidential, 2022 presidential and 2022 parliamentary source formats. It is designed for expansion to further compatible elections, but future source schemas require independent validation.

**Release v0.1.4 (23 October 2026):** This consolidated publication replaces the development patch sequence through v0.1.3.4-dev. The researcher reports that generated plots for zero, one and multiple polling stations now appear as expected. **The researcher confirmed successful regression tests, integration, complete execution and export checks for all three supported elections (presidential 2017, presidential 2022, parliamentary 2022).** The detailed transcript supplied for parliamentary 2022 covers seven commands, 7,787 Main stations and 436 figures; [validation record](VALIDATION_RECORD_2026-10-23.md). Equivalent presidential transcripts were not supplied. These results were not independently re-executed by the package assembler. The analytic definitions and formulas are unchanged from the development module. This module **does not implement the complete Jiménez–Hidalgo–Klimek (JHK) forensic test**, and unusual curves do not establish fraud.

## Capabilities

The script provides both original-style figure families: **A** compares selected candidates/electoral lists in one polling-station group, and **B** compares one candidate/list across groups. A graphs retain combined and option-faceted plots, now with **two-row legends for three or more options**. B combined graphs are **split into standard (up to six curves) and JHK (two curves) files**; B faceted graphs show these in **two separate panels**. Full option names appear in subtitles instead of long main titles. Optionally export PNG, PDF or both, with bilingual English/Serbian-Latin labelling in **one run**, translations and individual HEX colours. National figures are the default; individual districts/municipalities can be requested without producing thousands of maps or plots. All option vote totals are summarised numerically at national, district and municipality levels; national cumulative curves are calculated for every option irrespective of plot selection.

The eight available reporting groups are `ALL`, `GE100` (the default `Main` sample), `LT100` (QC-accepted only), `SMALL`, `MIDDLE`, `LARGE`, `JHK_SMALL`, `JHK_LARGE`. `Size` and `Size_JHK` are read **as supplied**, never recomputed. Overlapping groups must **not** be summed together. Optional descriptive T90/T95 bloc margins require an explicit, user-defined bloc membership. **No permutation-based significance claim** is generated.

The two curve normalisations are `valid` (cumulative option votes divided by all valid ballots in the group, ending at the option's group vote share) and `option` (cumulative option votes divided by that option's total votes, ending at 100% for nonzero votes). See [METHODOLOGY.md](METHODOLOGY.md).

**Single-station plotting groups:** When a selected area has only one eligible polling station in a size category, it is plotted as a point rather than a line (e.g., Overseas/Large in 2022). Statistical tables are unchanged.

**Special reporting categories:** plot titles use the RZS `District_code`: `33` = Overseas, `55` = Prisons (without a `district` suffix). For Kosovo-associated codes `25–29`, the official source label is retained without inventing a territorial suffix. See [USER_GUIDE.md](USER_GUIDE.md).

## Install and run

Install R (RStudio optional), then in R:

```r
install.packages(c("readxl", "openxlsx", "ggplot2", "readr"))
```

Prepare the three official RZS workbooks using the first toolkit module; retain them **locally** under `../rzs_data_preparation/RZS_prepared/`. Open `modules/klimek` as the RStudio working directory. In `Klimek.R`, change only **EDITABLE / KORISNIČKA PODEŠAVANJA**, including `INPUTS`, languages, plot selection and styling. Execute:

```r
source("tests/run_tests.R")
source("tests/test_graphics_layout.R")
source("tests/test_single_station_plots.R")
source("tests/test_zero_station_groups.R")
source("tests/integration_real_data.R")
source("Klimek.R")
source("tests/check_exports.R")
```

The output is organised by election under `klimek_outputs/`, with `tables/`, `curves/` and `figures/<EN|SR>/<valid|option>/...`. The source XLSX files are never overwritten. CSV uses UTF-8 BOM to preserve Serbian characters in Excel; for PDF use a Unicode-capable font if your installation needs one.

## Interpretation, limitations and citation

A cumulative curve visualises how votes accumulate as polling stations are ordered by reported turnout. Its shape can reflect electorate size, spatial composition, mobilisation, demographic patterns, or data issues, not necessarily wrongdoing. Comparisons between the same districts or matched polling stations, independent observation evidence, protocol review and relevant inferential modelling would be required to investigate unusual patterns. See [USER_GUIDE.md](USER_GUIDE.md) and [VALIDATION.md](VALIDATION.md).

Suggested citation: Kovačić, Z. J. (2026). *Election Forensics R Toolkit: Klimek-style cumulative curves* (v0.1.4) [R script]. GitHub repository, commit/release to be added upon publication. Root [MIT licence](../../LICENSE). Report bugs through repository Issues.


### Empty groups (included in v0.1.4)

Territorial exports explicitly include area × eight reporting groups × option combinations with no polling stations (`Stations=0`, zero counts, undefined shares/turnout as literal `NA` in the district/municipality CSV and Excel sheets). Such groups produce **no curves**. One-station groups are shown as dots; groups with two or more observations as lines. Each area receives one concise empty-group message. Rerunning removes earlier Klimek A/B images for the same plotted area before saving the new figures, so empty-group images do not persist. See `tests/test_zero_station_groups.R` and `USER_GUIDE.md`. Only areas represented in the eligible `ALL` station population are included in territory summary tables.
