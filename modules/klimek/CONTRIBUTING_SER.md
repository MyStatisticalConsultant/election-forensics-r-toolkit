# Saradnja na razvoju

[English](CONTRIBUTING.md)

Prijavite greške ili predloge preko GitHub Issues ili pošaljite pull request. Pre izmene formule navedite vrstu i format izbora, promenljive koje se menjaju, statističko obrazloženje i posledice po uključivanje BM. Dodajte sintetičke testove i kontrolu stvarnih baza. Nikada ne menjajte neprimetno pripremljenu ili zvaničnu izvornu evidenciju. Svaki novi test značajnosti mora definisati odbranjivu nultu hipotezu i po potrebi uzeti u obzir geografsku strukturu i višestruka poređenja. Poželjna je dvojezična dokumentacija i pristupačan izbor boja. Originalne Excel baze i automatski generisani izlazi ne treba dodavati u obične Git commit-e.
